# Face Tracking Photo Overlay

Upload a photo and watch it move with your face! Real-time face detection without showing your camera feed.

## Features

✨ Upload any photo  
📷 Face tracking with hidden camera  
🎬 Photo moves & scales with face  
🚀 Vercel-ready deployment  

## Quick Start

```bash
npm install
mkdir uploads
npm run dev
```

Visit http://localhost:3000

## Deploy to Vercel

1. Push to GitHub
2. Go to vercel.com
3. Import your repo
4. Deploy!

## How to Use

1. Upload a photo
2. Click "Start Camera"
3. Move your face and watch the photo follow!

The camera feed stays hidden - only your photo responds to your movements.
